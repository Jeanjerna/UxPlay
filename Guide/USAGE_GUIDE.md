# คู่มือการใช้งาน UxPlay (Usage Guide)

คู่มือนี้อธิบายวิธีใช้งาน UxPlay บนระบบปฏิบัติการ Windows หลังจากที่ทำการคอมไพล์และติดตั้งตาม [คู่มือการติดตั้งบน Windows](file:///d:/Programming Project/UxPlay/WINDOWS_INSTALL_GUIDE.md) เรียบร้อยแล้ว

---

## 1. วิธีเริ่มต้นเปิดใช้งานเซิร์ฟเวอร์
ให้เปิดโปรแกรม **MSYS2 UCRT64** หรือ **Windows Terminal** แล้วสั่งรันไฟล์ `uxplay` ด้วยการกำหนดพารามิเตอร์ต่าง ๆ ตามต้องการ:

*   **รันแบบปกติทั่วไป (แสดงผลจอหลัก):**
    ```bash
    uxplay
    ```
*   **รันพร้อมระบบขับเสียง WASAPI (แนะนำสำหรับ Windows):**
    ```bash
    uxplay -as wasapisink
    ```
*   **รันพร้อมระบบ Direct3D 12 และกด Alt+Enter เพื่อขยายเต็มจอได้:**
    ```bash
    uxplay -as wasapisink -vs d3d12videosink
    ```

---

## 2. วิธีการเชื่อมต่อจากอุปกรณ์ Apple (iPhone / iPad / Mac)
1. ตรวจสอบให้แน่ใจว่าอุปกรณ์ Apple และคอมพิวเตอร์ Windows เชื่อมต่ออยู่บน **Wi-Fi วงเดียวกัน**
2. ปัดหน้าจอของ iPhone/iPad ลงมาเพื่อเปิด **Control Center** (ศูนย์ควบคุม)
3. กดที่ปุ่ม **Screen Mirroring** (สะท้อนหน้าจอ)
4. เลือกชื่ออุปกรณ์สะท้อนหน้าจอ (ชื่อเริ่มต้นคือ `UxPlay`)
5. หน้าจอและเสียงจากอุปกรณ์จะไปแสดงผลบนระบบ Windows ทันที

---

## 3. ระบบยืนยันตัวตนและความปลอดภัย (PIN/Password)

เพื่อป้องกันบุคคลอื่นสตรีมหน้าจอมายังคอมพิวเตอร์ของคุณโดยไม่ได้รับอนุญาต (โดยเฉพาะเวลาใช้งานในวง Wi-Fi ที่แชร์ร่วมกับผู้อื่น) UxPlay มีพารามิเตอร์ควบคุมการเข้าถึง 2 แบบหลัก ๆ คือ:

### 3.1 ระบบ PIN Code (`-pin`)
การใช้ระบบ PIN ทำงานคล้ายกับ Apple TV โดยจะมีโค้ด 4 หลักปรากฏขึ้นมาบนหน้าจอของฝั่งเซิร์ฟเวอร์เพื่อนำไปกรอกบนอุปกรณ์ส่ง (Client)

*   **สุ่ม PIN ใหม่ทุกครั้งที่มีการเชื่อมต่อ:**
    ```bash
    uxplay -pin
    ```
    เมื่ออุปกรณ์ส่งเข้ามา จะมีรหัส PIN 4 หลักสุ่มแสดงขึ้นมาใน Terminal ของ Windows คุณต้องป้อนรหัสนี้ที่อุปกรณ์ Apple ของคุณเพื่อเริ่มส่งภาพ

*   **กำหนดรหัส PIN แบบตายตัว (4 หลัก):**
    ```bash
    uxplay -pin 1234
    ```
    (รหัส PIN ต้องมีค่าไม่เกิน 9999)

*   **เปิดการลงทะเบียนจับคู่เพื่อไม่ต้องกรอก PIN ซ้ำ (`-reg`):**
    หากไม่อยากป้อนรหัส PIN ทุกครั้งที่เชื่อมต่อใหม่ คุณสามารถให้ระบบจดจำอุปกรณ์ที่เคยจับคู่สำเร็จแล้วได้โดยระบุไฟล์สำหรับเก็บข้อมูล:
    ```bash
    uxplay -pin -reg paired_devices.txt
    ```
    *   **การเชื่อมต่อครั้งแรก:** อุปกรณ์ Apple จะต้องกรอก PIN 4 หลักที่แสดงบนจอ
    *   **การเชื่อมต่อครั้งถัดไป:** อุปกรณ์นั้นจะได้รับการอนุญาตโดยอัตนัติ ไม่ต้องกรอก PIN ซ้ำอีก เนื่องจากคีย์ของอุปกรณ์ถูกบันทึกไว้ในไฟล์ `paired_devices.txt` แล้ว

---

### 3.2 ระบบรหัสผ่านทั่วไป (`-pw`)
สามารถล็อกสิทธิ์การเข้าใช้งานได้ด้วยรหัสผ่านปกติ

*   **กำหนดรหัสผ่านตายตัวสำหรับเครื่องส่งทั้งหมด (ความยาวอย่างน้อย 4 ตัวอักษร):**
    ```bash
    uxplay -pw mysecretpassword
    ```
    อุปกรณ์ทุกตัวที่ต้องการเชื่อมต่อจะต้องป้อนรหัสผ่าน `mysecretpassword` ก่อนจึงจะสะท้อนหน้าจอได้

*   **สุ่มรหัสผ่านใหม่ทุกครั้งที่มีการเชื่อมต่อใหม่:**
    ```bash
    uxplay -pw
    ```
    (หากไม่ได้ระบุรหัสผ่านหลัง `-pw` ระบบจะทำตัวคล้ายกับ PIN โดยสุ่มรหัส 4 หลักแสดงบน Terminal ทุกครั้งที่มีการเชื่อมต่อใหม่และให้ผู้ใช้อุปกรณ์กรอกรหัสนี้ก่อนแชร์หน้าจอ)

---

## 4. วิธีการปิดการทำงาน (Exit)
หากต้องการปิดโปรแกรม UxPlay ให้กดปุ่ม **คีย์บอร์ด** ต่อไปนี้ที่หน้าต่าง Terminal ของคุณ:
*   กดปุ่ม `Ctrl + C` เพื่อหยุดการทำงานของเซิร์ฟเวอร์
*   (หากเปิดหน้าต่างวิดีโออยู่) สามารถกดปุ่ม `q` หรือปิดหน้าต่างสะท้อนภาพเพื่อยกเลิกการแสดงผลได้
